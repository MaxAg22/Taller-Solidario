# Taller Solidario

Inventory management system for a workshop dedicated to repairing notebooks and other equipment for donation to spaces in need.

## Tech Stack

- **React + Vite**: Frontend framework and build tool.
- **TypeScript**: Static typing for better code quality.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Shadcn UI**: Reusable components built with Radix UI and Tailwind CSS.
- **TanStack Query**: Asynchronous state management for data fetching.
- **Zod**: Schema declaration and validation library.
- **React Hook Form**: Flexible forms with easy validation.
- **Supabase**: Backend-as-a-Service for database and authentication.
